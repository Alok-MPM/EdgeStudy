# Chemistry

Put each chapter's notes in its own folder here. Nothing else has to be edited: the app finds the files by name.

```
subjects/chemistry/<chapter-folder>/theory.html
subjects/chemistry/<chapter-folder>/questions.html
subjects/chemistry/<chapter-folder>/revision.html
```

All three files are optional. A chapter shows "Notes available" as soon as at least one of them exists.

| # | Chapter | Folder name |
|---|---------|-------------|
| 1 | Solutions | `solutions` |
| 2 | Electrochemistry | `electrochemistry` |
| 3 | Chemical Kinetics | `chemical-kinetics` |
| 4 | The d- and f-Block Elements | `the-d-and-f-block-elements` |
| 5 | Coordination Compounds | `coordination-compounds` |
| 6 | Haloalkanes and Haloarenes | `haloalkanes-and-haloarenes` |
| 7 | Alcohols, Phenols and Ethers | `alcohols-phenols-and-ethers` |
| 8 | Aldehydes, Ketones and Carboxylic Acids | `aldehydes-ketones-and-carboxylic-acids` |
| 9 | Amines | `amines` |
| 10 | Biomolecules | `biomolecules` |

Example: `subjects/chemistry/solutions/theory.html`
