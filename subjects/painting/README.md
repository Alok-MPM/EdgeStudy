# Painting

Put each chapter's notes in its own folder here. Nothing else has to be edited: the app finds the files by name.

```
subjects/painting/<chapter-folder>/theory.html
subjects/painting/<chapter-folder>/questions.html
subjects/painting/<chapter-folder>/revision.html
```

All three files are optional. A chapter shows "Notes available" as soon as at least one of them exists.
