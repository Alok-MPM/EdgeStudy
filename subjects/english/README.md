# English

Put each chapter's notes in its own folder here. Nothing else has to be edited: the app finds the files by name.

```
subjects/english/<chapter-folder>/theory.html
subjects/english/<chapter-folder>/questions.html
subjects/english/<chapter-folder>/revision.html
```

All three files are optional. A chapter shows "Notes available" as soon as at least one of them exists.

| # | Chapter | Folder name |
|---|---------|-------------|
| 1 | Reading Comprehension | `reading-comprehension` |
| 2 | Writing Skills | `writing-skills` |
| 3 | Flamingo: Prose | `flamingo-prose` |
| 4 | Flamingo: Poetry | `flamingo-poetry` |

Example: `subjects/english/reading-comprehension/theory.html`
